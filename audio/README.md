# Musik

Zwei Dateien werden hier gesucht:

- `menu.mp3` läuft auf der Startseite und im Raum.
- `game.mp3` läuft während des Spiels, etwas leiser, damit die Geräusche durchkommen.

Beide laufen in einer Schleife. Beim Wechsel zwischen Menü und Spiel wird übergeblendet, jedes Stück macht dort weiter, wo es war. Fehlt eine Datei, bleibt es an dieser Stelle still. Der Schalter „Musik“ steht oben rechts im Menü und unten rechts im Spiel, der Browser merkt sich die Einstellung.

Das Repository und die Seite auf GitHub Pages sind öffentlich. Hier sollte deshalb nur Musik liegen, die öffentlich weitergegeben werden darf, etwa mit einer freien Lizenz oder selbst gemacht.
