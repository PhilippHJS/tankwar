# Musik

Liegt hier eine Datei `menu.mp3`, läuft sie auf der Startseite und im Raum als Menümusik in einer Schleife. Beim Wechsel ins Spiel blendet sie sich aus, danach wieder ein. Oben rechts lässt sie sich stummschalten, der Browser merkt sich das.

Fehlt die Datei, bleibt es still und der Knopf erscheint nicht.

Das Repository und die Seite auf GitHub Pages sind öffentlich. Hier sollte deshalb nur Musik liegen, die öffentlich weitergegeben werden darf, etwa mit einer freien Lizenz oder selbst gemacht.
